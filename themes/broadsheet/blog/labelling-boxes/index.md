Every box in my first move said "misc". By the third move I had a system, and it fits on one line.

## Room, then contents, then a number

Write the destination room first, in capitals. Then write three things that are in the box. Then number it.

```
KITCHEN / kettle, mugs, tea towels / 07
```

The room tells the movers where to put it. The contents tell you if you need it tonight. The number tells you if one is missing.

## Label two sides

Boxes get stacked. A label on the top is hidden by the box above it. Put the label on one long side and one short side.

That is all. It takes ten seconds for each box and saves a week of opening the wrong ones.
